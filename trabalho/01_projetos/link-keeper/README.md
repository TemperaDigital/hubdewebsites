# Link Keeper

Eu quero criar um site, uma aplicação web  para ser uma especie de biblioteca de links, uma linkoteca, aonde eu possa catalogar e guardar os links dos sites de meu interessa que eu encontro pela web, coloque ele no campo de entrada ele cria o card e eu tenho a opção de clarrifcar o link, colocar uma # para facilitar a localização e ter um campo de anotação para escrever notas sobre o card. Para manter o registro vou querer usar o meu banco de dados externo supabase que possui coentor aqui.  Não há a necessidade de criar entrada com autenticação.
